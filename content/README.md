# 디지털시민교육 연구·연수·수업 설계 지식 베이스

이 볼트는 **디지털 시민교육(Digital Citizenship Education)** 분야의 연구 논문, 국내외 정책 문서, 교사 연수 프로그램, 수업 설계 사례를 체계적으로 축적하고 연결하는 Obsidian 기반 지식 베이스입니다. 초등 교사이자 SW·AI 교육 연구자의 관점에서, 디지털 시민 역량 6요소 모델부터 2022 개정 교육과정, 경기도교육청 5분 실천 사례까지 현장에서 바로 활용할 수 있는 지식을 연결하고 종합하는 것을 목표로 합니다.
