# 경기도교육청 디지털 시민교육 정책

> [!note] 후속 계획 안내
> 2025년 1월 경기도교육청은 [[2025-gyeonggi-plan|2025 디지털 시민교육 기본 계획]]을 발표했다.
> **인성 기반 6대 영역 재구조화 + 디지털 창의역량 트랙 신설 + 인정도서 2종 보급** 등 본 페이지 이후의 후속 변화는 해당 페이지를 참고할 것.

## 개요

경기도교육청은 전국 최초로 디지털 시민교육을 정규 교과로 신설하고 2025학년도부터 시행했다. 초등 4학년을 대상으로 한 학기 29차시 수업을 운영하며, 5분+ 실천 프로그램·하이러닝 플랫폼·디지털 시민 배지 수여 등 다층적 지원 체계를 구축했다.

---

## 전국 최초 정규 교과 신설 (2025~)

### 교과서: 『초4 미래를 여는 디지털 시민』

| 항목 | 내용 |
|------|------|
| **대상** | 초등 4학년 |
| **시수** | 한 학기 **29차시** |
| **시행** | 2025학년도부터 (전국 최초) |
| **연계 플랫폼** | 하이러닝(HiLearning) |
| **수료 인센티브** | 디지털 시민 배지 수여 |

#### 단원 구성 (4단계 반복 구조)

1. **디지털 역량 지식 탐구** — 개념 이해 및 사례 분석
2. **다양한 활동 전개** — 토의·토론·역할극 등 참여 활동
3. **디지털 도구 활용 문제 해결** — 실습 기반 문제해결 학습
4. **실생활 실천** — 일상 속 디지털 시민 행동 연습

## 5대 핵심 가치

| 가치 | 의미 |
|------|------|
| **소통** | 디지털 환경에서의 올바른 표현과 대화 |
| **참여** | 온라인 사회참여와 공동체 기여 |
| **책임** | 자신의 디지털 행동에 대한 책임 인식 |
| **윤리** | 디지털 환경에서의 도덕적 판단 |
| **안전** | 개인정보 보호, 사이버폭력 예방, 보안 |

## 디지털 역량 진단 도구

### 하이랜드 (HiLand) 메타버스 플랫폼

- **형식**: 메타버스 기반 자가진단
- **기능**: 디지털 역량 진단 + 맞춤형 피드백 제공
- **특징**: 게임형 인터페이스로 학생 흥미 유발, 진단 결과에 따른 개인화 학습 경로 제공

## 교원 지원 체계

| 지원 요소 | 내용 |
|-----------|------|
| **정책 자문단** | 초·중·고 교원 + 전문가 구성 |
| **디지털 시민교육 네트워크** | 지역 연계 교원 공동체 |
| **원격 연수** | 연 10회 운영 |
| **실천학교** | 디지털 시민교육 실천학교 100개교 운영 (2023 경기도교육연구원 분석) |

## 전국 확산 동향

- 경기도 모델이 타 시도교육청에서 참조 및 벤치마킹 중
- [[5min-practice|5분+ 실천 프로그램]]은 초등에서 중고등까지 확대 운영 중
- 디지털 시민 배지 시스템이 타 시도 포트폴리오 제도와 연계 논의 중
