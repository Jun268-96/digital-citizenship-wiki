# 디지털시민교육 위키 — Claude 작업 스키마

## 볼트 목적

이 볼트는 **디지털 시민교육 연구·연수·수업 설계**를 위한 지식 베이스다.
초등 교사이자 SW·AI 교육 연구자가 관련 논문, 정책 문서, 연수 자료, 수업 설계 사례를
체계적으로 축적하고 종합적으로 분석하기 위해 구성되었다.

---

## 디렉토리 구조

```
~/디지털시민교육-wiki/
├── CLAUDE.md          ← 이 파일: Claude 작업 스키마
├── README.md          ← 사람이 읽는 소개
├── index.md           ← 전체 목차 + 교차 참조 지도
│
├── concepts/          ← 핵심 개념, 이론, 역량 모델, 프레임워크
├── papers/            ← 논문·연구 보고서 요약
├── resources/         ← 수업·연수 자료, 도구, 플랫폼
├── policy/            ← 교육과정·정책 문서 분석
├── training/          ← 교사 연수 설계 및 운영 사례
└── synthesis/         ← 종합 분석, 비교, 시사점 도출
```

## 파일 컨벤션

### Frontmatter 템플릿

모든 위키 페이지는 아래 frontmatter로 시작한다:

```yaml
---
title: (한국어 제목)
tags: [디지털시민교육, (카테고리 태그)]
source: (출처 URL 또는 파일명 — 없으면 생략)
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

카테고리 태그 예시: `concept`, `paper`, `policy`, `resource`, `training`, `synthesis`

### 파일명 규칙

- kebab-case 영문 소문자 사용: `digital-literacy-framework.md`
- 연도 포함 시 앞에 배치: `2025-star-project.md`
- 공백 없이, 특수문자 없이

### 위키링크 문법 (Obsidian 호환)

- 같은 디렉토리: `[[filename]]` 또는 `[[filename|표시 텍스트]]`
- 하위 디렉토리: `[[concepts/6-competencies]]`
- 상위로 이동: `[[../papers/2025-star-project]]`

### 출처 인용 규칙

- 논문: `> 출처: 저자명(연도). 제목. 저널/보고서.`
- 웹페이지: `> 출처: [제목](URL) — 접근일: YYYY-MM-DD`
- 정책 문서: `> 출처: 발행기관(연도). 문서명.`

## 교차 참조 원칙

1. **고립 페이지 금지**: 모든 페이지는 최소 2개의 위키링크를 포함해야 한다.
2. **양방향 링크**: A → B 링크 추가 시, B의 "관련 항목" 섹션에도 A를 추가한다.
3. **index.md 동기화**: 새 페이지 추가 시 `index.md`의 목차에도 반드시 등록한다.
4. **synthesis 우선**: 단순 나열보다 개념 간 연결과 시사점 도출을 우선한다.
