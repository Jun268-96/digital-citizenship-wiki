## 연구 흐름 (시간순)

```
2022 ─ 척도 개발 (진단 도구 마련)
  │
2023 ─ 교육과정 현황 진단 (사회과, 도덕과 분석)
  │     + 민간 효과성 연구 (카카오임팩트)
  │
2024 ─ 전 교과 성취기준 비교 분석 (2015 vs. 2022)
  │     → 초등 단계 취약성 확인
  │
2025 ─ 실천적 해결책 제시 (S.T.A.R 융합 프로그램)
        → 4역량 전부 유의미하게 향상
```
